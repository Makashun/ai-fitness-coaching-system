# AI-Based Personal Fitness Coaching System

## Project Overview

This project aims to design and develop an AI-Based Personal Fitness Coaching System that provides personalised fitness recommendations based on users' health indicators, physical characteristics, and fitness goals.

The system will investigate how Artificial Intelligence (AI) and Machine Learning (ML) techniques can be applied to generate personalised exercise recommendations and assist users in achieving their fitness objectives.

This project is being developed as part of the UWE Information Technology Project module.

---

## Research Question

Can an AI-based recommendation system generate effective and personalised fitness recommendations based on users' health indicators, physical characteristics, and fitness goals?

---

## Objectives

1. Investigate existing AI fitness coaching and recommendation systems.
2. Analyse user requirements for personalised fitness coaching.
3. Design and evaluate an AI-based recommendation model.
4. Develop a web-based fitness coaching platform.
5. Evaluate the effectiveness and usability of the proposed system.

---

## Health Indicators

The proposed system may consider the following health indicators:

- BMI (Body Mass Index)
- Blood Pressure
- Blood Sugar
- Cholesterol
- Body Fat Percentage
- Visceral Fat
